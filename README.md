# ☀️ Le petit monde d’Amélia

**Le petit monde d’Amélia** is an interactive French-learning game designed for young beginners. It turns language revision into a playful adventure with colorful illustrations, short activities, and immediate feedback.

The project is designed for French lessons with an eight-year-old learner and can be used both during online classes and for independent practice.

## 🎯 Project Goals

- Make French revision engaging and accessible for young learners.
- Practise vocabulary, basic sentence structures, numbers, colours, and days of the week.
- Combine different exercise formats to encourage active participation.
- Support both teacher-led activities and independent learning.

## 🗺️ Game World

The game is organised around four locations:

- **Moi et mon petit monde** — introducing yourself, personal information, and familiar animals.
- **Le jardin** — animals, colours, numbers, and counting.
- **Le parc** — everyday actions, personal pronouns, and days of the week.
- **Le coin des goûts** — likes and dislikes, expressing preferences, and simple dialogues.

Each location contains activities focused on practising French vocabulary and expressions introduced during lessons.

## 🎮 Interactive Activities

The game is designed to include a variety of exercises:

- Matching pictures with French words.
- Completing a character profile.
- Identifying characters from descriptions.
- Counting objects and entering answers.
- Selecting objects by colour.
- Matching characters with actions.
- Practising personal pronouns and verb forms.
- Arranging weekdays in the correct order.
- Building French sentences from individual words.
- Sorting items into categories.
- Completing short dialogues and arranging their lines.

## ⭐ Progress and Rewards

The game features a reward system with up to four stars, one for completing each location.

Progress is intended to reflect completed activities rather than individual clicks, encouraging learners to work through each section.

## 👩‍🏫 Learning Approach

The project follows a beginner-friendly, activity-based approach:

- Instructions are provided in Russian.
- French is used for target vocabulary, phrases, and dialogues.
- Exercises focus on material introduced during lessons.
- Activities combine recognition, recall, and sentence-building practice.
- Feedback helps learners identify correct answers and try again when necessary.

The game is intended to complement lessons rather than replace structured language instruction.

## 🛠️ Technologies

The project uses standard web technologies:

- HTML
- CSS
- JavaScript

The goal is to make the game accessible through a web browser without requiring a separate application installation.
