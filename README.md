# Le petit monde d’Amélia

Статический интерактивный сайт для публикации на GitHub Pages.

## Публикация
1. Создайте публичный репозиторий `amelialaclasse` в аккаунте `gussevaelizaveta`.
2. Загрузите **все файлы и папку из содержимого этого архива** в корень репозитория.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, затем `main` и `/(root)`, нажмите **Save**.

Ожидаемый адрес: https://gussevaelizaveta.github.io/amelialaclasse/

Изображение карты находится в `images/map.webp`; фавикон и превью соцсетей хранятся локально. Сайт не требует внешних библиотек для основной работы.
